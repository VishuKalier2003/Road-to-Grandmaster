# Road to Grandmaster

This repository separates practice, reusable knowledge, and revision.

## Repository map

| Area | Purpose |
|---|---|
| [`codeforces/`](codeforces/) | Codeforces solutions, grouped by rating |
| [`cses/`](cses/) | CSES solutions, grouped by topic |
| [`algorithms/`](algorithms/) | Reusable implementations and templates |
| [`z-cp-notes/`](z-cp-notes/) | Concept and pattern notes for recall |
| [`problem-sheets/`](problem-sheets/) | Curated problem lists and revision tracking |

## Learning workflow

1. Add a problem to the relevant sheet before or after attempting it.
2. Keep the accepted solution in its platform folder.
3. Record the trigger, key observation, and mistake in the sheet.
4. When an idea repeats, add or update one note in `z-cp-notes/` and link it from the sheet.
5. Use the next-review date to choose revision problems instead of selecting them randomly.

## Note format

For quick recollection, concept notes should answer these questions in this order:

- **Trigger:** What wording or constraints suggest this idea?
- **Mistake:** What tempting approach fails or wastes time?
- **Idea:** What is the reusable reasoning?
- **One-liner:** What should be remembered during a contest?
- **Problems:** Where was the pattern used?

This is already close to the structure used in `z-cp-notes/`, so existing notes do not need to be moved.
